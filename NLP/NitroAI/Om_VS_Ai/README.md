## Documentation

The solution addresses two subtasks using a combination of supervised and unsupervised learning on text data. Subtask 1 employs a TfidfVectorizer with word n-grams and a LinearSVC classifier, while Subtask 2 uses KMeans clustering to categorize text into four thematic areas: Science, Crime, Business, and Religion. This dual approach leverages both labeled and unlabeled data patterns effectively.

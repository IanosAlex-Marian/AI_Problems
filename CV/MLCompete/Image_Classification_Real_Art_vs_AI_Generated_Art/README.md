## Documentation

The solution employs a fine-tuned EfficientNet-B0 model to differentiate between real and AI-generated artwork. Data preprocessing included standardizing image dimensions and applying augmentations such as random flips and color jittering. The model was optimized using AdamW over five epochs to provide reliable binary classification.

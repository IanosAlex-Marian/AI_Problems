This project is part of the [MLCompete](https://platform.olimpiada-ai.ro/en) challenges.

- [Jupyter Notebook](./main.ipynb)
- [Back to Main README](../../../README.md)

## Documentation

The solution involves decomposing 256x256 land images into 4x4 grids of 64x64 cells. A custom Convolutional Neural Network (CNN) was trained to classify individual cells, and the resulting predictions were aggregated to form a binary representation of the land. This approach allows for detailed spatial analysis and efficient data encoding.

## Documentation

This problem was addressed by fine-tuning a pre-trained EfficientNet-B0 model to classify cartoon characters into four distinct categories. Images were standardized to a 224x224 resolution and processed through a linear classifier. The model was trained over ten epochs using the Adam optimizer, achieving effective multiclass differentiation.

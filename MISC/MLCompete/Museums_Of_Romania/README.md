## Documentation

The project focuses on analyzing a dataset of museums in Romania to extract various statistics and insights. It involves:
1. **Data Exploration:** Analyzing the dataset to calculate general statistics such as the total number of museums and specifically those located in Bucharest.
2. **Missing Value Analysis:** Identifying the number of columns with missing data and determining the most frequent year of establishment for the listed museums.
3. **Geographic Distribution:** Calculating the count of museums for each county to understand the cultural density across different regions of Romania.
4. **Data Completeness:** Computing a completeness score for each museum record based on the availability of information across all fields, and calculating aggregate statistics like average completeness.
5. **Automated Submission:** Consolidating all analysis results into a structured `submission.csv` file for the competition.
